# 🧠 יומן CBT

יומן תרגול אישי לכלים מעולם הטיפול הקוגניטיבי-התנהגותי (על פי שיטת ד"ר מלאני פנל).

> 🔒 **כל מה שנכתב נשמר רק אצל המשתמש** — בדפדפן של הטלפון/המחשב שלו. אין הרשמה, אין שרת, שום דבר לא נשלח החוצה.

## איך משתמשים (למשתמש)

1. פותחים את הקישור. בפעם הראשונה מופיע הסבר קצר (אפשר לפתוח אותו שוב בכפתור "❓ איך זה עובד?").
2. לוחצים **"✍️ תרגול חדש"**, בוחרים סוג תרגול וכותבים. הכל נשמר אוטומטית גם תוך כדי כתיבה.
3. ב-**"📋 היומן שלי"** רואים, מחפשים, עורכים ומוחקים רשומות.
4. פעם בשבוע לוחצים **"💾 גיבוי"** ← "שמור גיבוי" ושולחים את הקובץ לעצמם (וואטסאפ / דרייב).

מדריך מוכן לשליחה למשתמש: [`הודעה_למשתמש.md`](הודעה_למשתמש.md)

## קבצים

* [`index.html`](index.html) — כל האפליקציה בקובץ אחד. אין תלות בספריות או שירותים חיצוניים.
* [`הודעה_למשתמש.md`](הודעה_למשתמש.md) — ההודעה והמדריך לשליחה למשתמש.

## הפעלה (למפתח)

הדרך הכי פשוטה: GitHub Pages — Settings ← Pages ← Branch `main` ← Save. הקישור יהיה `https://danielhaimov11.github.io/cbt-workbook/`.
אפשר גם לפתוח את `index.html` ישירות מהמחשב.

## פרטיות ומשפטי

* **אין איסוף מידע:** אין שרת, מסד נתונים, הרשמה, עוגיות או אנליטיקס. המפתח לא מקבל ולא מחזיק שום מידע על המשתמשים — ולכן אין "מאגר מידע" שלו.
* **חסימה טכנית:** `Content-Security-Policy` בדף חוסם כל שליחה או טעינה מהרשת.
* **אירוח:** GitHub Pages (כמו כל אתר) רושם כתובות IP של מבקרים לצרכי אבטחה, תחת מדיניות הפרטיות של GitHub. למפתח אין גישה לרישומים האלה.
* **הבהרה:** כלי עזר לתרגול עצמי, אינו תחליף לטיפול מקצועי. מוצגים מספרי חירום (ער״ן 1201, מד״א 101).
* **זכויות יוצרים:** השאלות נוסחו מחדש במילים פשוטות בהשראת שיטת Melanie Fennell, ללא העתקת טקסט מהספר.

## פרטים טכניים

* שמירה ב-`localStorage` (מפתח `cbt_standalone_records_v1`, תואם לגרסאות קודמות). טיוטה נשמרת אוטומטית.
* גיבוי = קובץ JSON (`CBT-backup-YYYY-MM-DD.json`); בטלפון נשלח דרך תפריט השיתוף.
* מבוסס על המתודולוגיה של Melanie Fennell. לשימוש אישי ולימודי.
