# מרחב תרגול CBT | Interactive CBT Workbook

מערכת אינטראקטיבית עצמאית לתרגול ויישום עקרונות טיפול קוגניטיבי-התנהגותי (CBT), המבוססת על מודל הטיפול של ד"ר מלאני פנל (*Melanie Fennell* - מחברת "הערכה עצמית נמוכה: מבוא והשפעות").

המערכת פועלת במלואה ישירות מתוך הדפדפן (Client-Side Only), ללא צורך בהתקנת שרת, ומבטיחה פרטיות מוחלטת של הנתונים האישיים.

## 🌟 תכונות מרכזיות (Key Highlights)

- 🔒 **פרטיות ואבטחת מידע מלאה**: המידע נשמר אך ורק בזיכרון המקומי של המכשיר (`localStorage`). שום מידע אינו נשלח לשרת חיצוני.
- 📊 **דו-כיווניות עם Excel**: ייצוא נתונים מרוכזים לקובץ `.xlsx` עם גליונות נפרדים לכל פרק, וייבוא/מיזוג קבצי Excel קיימים ישירות למערכת (מופעל ע"י SheetJS).
- 📱 **ממשק מודרני ותגובתי (Responsive)**: תמיכה מלאה בעברית (RTL), טיפוגרפיה נקייה (פונט Rubik), עיצוב מותאם לנייד ולמחשב (Tailwind CSS).
- 🧩 **אפס תלויות שרת**: קובצי HTML עצמאיים לחלוטין הניתנים לפתיחה בכל דפדפן.

## 🗂️ פירוט הגרסאות בפרויקט

הפרויקט כולל שתי גרסאות המציגות את התפתחות המערכת (לתיעוד מלא ראו את [יומן השינויים (CHANGELOG.md)](CHANGELOG.md)):

### 1. גרסה 1 (`CBT_Workbook.html`)
גרסת הבסיס המאפשרת הזנה, תרגול ושמירה מקומית של שני דפי עבודה מרכזיים:
* **פרק 4: בדיקת תחזיות חרדתיות וניסויים התנהגותיים**:
  * **חלק א' - זיהוי בזמן אמת**: תיעוד תאריך, טריגר/מצב, רגשות ותחושות גופניות (0–100), תחזית חרדתית ואמצעי זהירות/הגנה.
  * **חלק ב' - הטלת ספק ובחינה מחדש**: ראיות בעד ונגד התחזית, ניתוח תרחיש קיצון (הגרוע מכל) מול התרחיש הסביר ביותר, וגיבוש מחשבה חלופית מאוזנת.
  * **חלק ג' - ניסוי התנהגותי בעולם האמיתי**: תכנון פעולה, ויתור יזום על אמצעי הגנה ("התנהגות ביטחון"), תיעוד התוצאה בפועל ומתן קרדיט עצמי.
* **פרק 3: שרטוט מעגל הקסמים האישי וניתוח טריגרים**:
  * **שלב 1 - זיהוי הטריגר**: זיהוי המצב והכלל לחיים שהופר.
  * **שלב 2 - מעגל הקסמים**: ניתוח הספירלה היורדת בחמישה צעדים:
    1. הפעלת ה"שורה התחתונה" (אמונת ליבה שלילית).
    2. ניבויים שליליים ותחושות חרדה.
    3. התנהגות הגנתית / אמצעי זהירות.
    4. אישור מוטעה של האמונה וביקורת עצמית.
    5. דיכאון / מצב רוח ירוד.
* **ניהול נתונים**: ספירת רשומות, הורדת אקסל יזומה, מיזוג מקובץ אקסל קיים, ואיפוס זיכרון מקומי.

---

### 2. גרסה 2 (`CBT_WorkbookV2.html`) — גרסה מתקדמת ומלאה
מרחיבה את גרסה 1 ומוסיפה מערכת ניהול, חיפוש ועריכה מקיפה:
* 📋 **לשונית "היסטוריה ועריכה" (History & Record Management)**:
  * **טבלת רשומות מרוכזת**: צפייה בכל הרשומות של שני הפרקים במקום אחד עם תגיות צבע ברורות.
  * 🔍 **חיפוש חופשי בזמן אמת**: סינון מיידי של רשומות לפי טקסט (מצב, טריגר, מחשבה, תוצאה, תאריך וכו').
  * 📂 **סינון לפי פרק**: אפשרות לצפות בכל הרשומות יחד, או לסנן לפרק 3 או פרק 4 בלבד.
  * 👁️ **חלון תצוגה מקדימה מלא (Modal)**: פתיחת כרטיסייה מעוצבת לצפייה מעמיקה בכל שדות הרשומה שנשמרה.
  * ✏️ **מצב עריכה מלא (Full In-Place Editing)**: טעינת רשומה קיימת חזרה לטופס הרלוונטי, עדכון השדות, שמירה ישירה של השינויים או ביטול עריכה.
  * 🗑️ **מחיקה פרטנית**: מחיקת רשומה ספציפית ללא צורך באיפוס כלל הנתונים.
* 🏷️ **תגיות מונה חכמות (Total Badge)**: חיווי חי בסרגל העליון של כמות הרשומות הכוללת והמפולחת.
* 🔔 **מערכת התראות מובנית**: הודעות משוב ויזואליות לשמירה, עריכה, ייבוא ואיפוס נתונים.

## 🛠️ טכנולוגיות (Tech Stack)

- **HTML5 & Vanilla JavaScript**: לוגיקה עצמאית, ללא תלות בספריות כבדות (Zero Framework Overhead).
- **Tailwind CSS (via CDN)**: עיצוב מודרני, תמיכה מלאה בכיווניות RTL.
- **SheetJS (xlsx.full.min.js)**: עיבוד, יצירה וקריאה של קובצי גיליונות אלקטרוניים בפורמט Excel.
- **Web Storage API (`localStorage`)**: שמירת נתונים מקומית ופרטית בצד לקוח.
