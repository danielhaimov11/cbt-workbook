# מרחב תרגול CBT | Interactive CBT Workbook

מערכת אינטראקטיבית לתרגול ויישום עקרונות טיפול קוגניטיבי-התנהגותי (CBT), המבוססת על מודל הטיפול של ד"ר מלאני פנל (*Melanie Fennell* - מחברת "הערכה עצמית נמוכה: מבוא והשפעות").

המערכת פועלת במודל **היברידי עצמאי (Client-Side & Serverless Cloud)**: היא מאפשרת עבודה מקומית מלאה במחשב ללא שרת, ובמקביל מאפשרת למשתמשים לסנכרן דו-כיוונית מול גיליון **Google Sheets פרטי בענן** – ללא צורך בתחזוקת שרת מרכזי וללא צורך בפרויקטי OAuth מורכבים ב-Google Cloud!

## 🚀 איך המערכת עובדת? (מענה לכל סוגי המשתמשים)

המערכת בגרסה 3 מעניקה חופש בחירה מוחלט והפעלה פשוטה במיוחד:

### ⭐ מסלול 1 (הכי קל ומומלץ): הפעלה בלחיצת כפתור אחת מתוך Google Sheets
**ללא צורך בהגדרת קישורים, ללא העתקת כתובות, וללא שום ידע טכני!**
1. פתחו גיליון Google Sheets חדש ב-Google Drive שלכם.
2. לחצו בתפריט העליון על **הרחבות (Extensions) &larr; Apps Script**.
3. הדביקו את הקוד מתוך [`Code.gs`](Code.gs) (או לחצו על "העתק קוד שרת" בחוברת) ושמרו (Ctrl+S).
4. רעננו את הגיליון — מיד יופיע לכם תפריט עליון חדש בגיליון:  
   👉 **`🧠 מרחב תרגול CBT` &larr; `🚀 פתח חוברת תרגול (חלון מלא)`**
5. **בלחיצת כפתור אחת זו המערכת נפתחת ישירות בתוך הגיליון!**  
   כל טופס שממלאים נכתב אוטומטית לשורות של `פרק_4_תחזיות` ו-`פרק_3_טריגרים` בזמן אמת.

---

### 📱 מסלול 2: הרצה ישירה מהטלפון הנייד או הדפדפן (ללא הורדת קובץ)
- בתוך גיליון ה-Google Sheets שבו הוגדר הקוד, לוחצים בתפריט העליון על:  
  **`🧠 מרחב תרגול CBT` &larr; `🔗 קישור להרצה ישירה מהטלפון / מחשב`**
- נפתח לכם קישור ה-Web App האישי שלכם.
- שמרו אותו במועדפים בנייד או במחשב — ולחיצה עליו מכל מקום תפתח את המערכת שלכם מעודכנת ומחוברת ישירות לגיליון!

---

### 💻 מסלול 3: עבודה מקומית במחשב (Excel בלבד)
- מורידים את הקובץ [`CBT_WorkbookV3.html`](CBT_WorkbookV3.html) (או מתוך ה-ZIP).
- לוחצים עליו דאבל-קליק והוא פועל מיד בכל דפדפן (גם ללא אינטרנט).
- הנתונים נשמרים במחשב שלכם ובכל שמירה יורד קובץ Excel מעודכן (`יומן_תרגול_CBT.xlsx`).
- *אופציונלי:* ניתן לחבר גם את הקובץ המקומי לענן באמצעות הזנת כתובת ה-Web App בחלון "☁️ הגדרות ענן".

## 🛠️ טכנולוגיות (Tech Stack)

- **Client**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS (CDN), Google Font Rubik (RTL).
- **Excel Engine**: SheetJS (`xlsx.full.min.js`).
- **Cloud Backend**: Google Apps Script (`SpreadsheetApp`, `ContentService`, `HtmlService`).
- **Local Storage**: Web Storage API (`localStorage`).
